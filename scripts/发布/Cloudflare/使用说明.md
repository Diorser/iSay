# 更新服务配置入口

本目录只包含更新文件 Worker，不包含官网。本轮未部署、未建桶、未写入账号或令牌。

在 Cloudflare 中准备 `isay-releases` R2 桶，将 `wrangler.jsonc` 的 `RELEASES` binding 指向该桶；申请域名后为 Worker 添加自定义域名。`workers_dev=false`，不使用 `r2.dev` 作为正式下载地址。凭据只从 Cloudflare 登录态或 `CLOUDFLARE_API_TOKEN` 环境变量提供。

部署需要发布环境中另行安装并固定官方 Wrangler CLI，核对其版本后在本目录运行 `wrangler deploy`。发行上传脚本使用 `npx --no-install wrangler`，不会自动拉取或运行未知版本。执行上传前先完成签名密钥与客户端公钥配置。

- 查询清单：`https://<正式域名>/v1/stable/win-x64/manifest.json`
- 清单在 R2 的对象键：`channels/stable/win-x64.json`
- 下载文件：`https://<正式域名>/objects/<SHA256>/<文件名>`
- 本地验证：在项目根运行 `node test/发行打包回归/Worker回归.mjs`

清单缓存 60 秒；哈希命名的文件缓存一年且不可变。上传脚本先上传并从实际域名下载核对哈希，最后才允许切换 stable；GitHub 可以作为清单中同内容文件的备用地址。变更 Worker 或发行脚本后，应在预览通道验证 Range、If-Range、ETag 与中断续传。
