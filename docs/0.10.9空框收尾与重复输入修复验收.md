# 0.10.9 空框收尾与重复输入修复验收

日期：2026-11-05。仅更新本机 iSay，不操作或重启用户当前 ChatGPT。

## 修复内容

- 0.10.8 已修复浏览器长文整理沿用无活动组合范围直接替换的问题。所有支持的 Chromium 目标都使用正文核验后的整理路径；结果没有改变时不再发送正文。
- 0.10.8 已修复 iSay 本页转写收尾等待外部交付标志的问题。隐藏真实 WPF 窗口的右 Alt 收尾专项覆盖旧交付标志未释放，确认界面调度持续响应、整段文本保留且无外部写入。这是已定位的一条阻塞路径，不能据此断言所有卡死原因都已排除。
- 0.10.9 移除“旧位置可能写过字就一律禁止结束补填”的限制。仅当原交付失败，旧组合确认结束，且结束键时固定的当前框在建立组合和提交正文前仍为空、焦点及物理输入版本均未变化，才补入完整转写。
- Chromium 无障碍快照存在短暂滞后。只读探测等待同一目标，要求连续两次为空；提交前仍重新验证。已有正文、焦点切换、用户手动修改和旧组合结束不确定时不追加全文。

## 发现但保留的保护边界

测试曾直接清空仍在活动组合中的编辑器状态，浏览器在结束旧组合时把旧文字恢复。当前实现会因重新核验后已非空而拒绝追加整段，保留完整转写在 iSay，不盲目覆盖。这与先实际失焦、旧组合已结束、再回到空框的成功用例分别记录；失败证据未删除。
