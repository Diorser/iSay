# iSay 0.10.5

本次更新集中修复常驻进程与输入交付的可靠性，沿用 0.9.7 原生输入组件。

- 修复一次空初始化失败后，旧会话清理永久阻塞后续录音，导致网页和桌面客户端均不出字的问题。
- 对明确未被接受的空初始化，在原输入位置和键鼠状态未变时允许一次安全恢复；不重发已可能写入的正文。
- 修复待机、组件重建、长时间失焦及切换取消时，旧请求漏清理或无法继续确认的问题。
- 修复由工具启动的客户端可能继承启动器整组退出限制的问题；必要时交由 Windows 桌面独立启动。
- 增加启动环境和输入清理诊断，不记录语音正文。

根目录 `test/TSF桥接回归/` 提供可独立运行的管道与会话回归。默认无需注册系统输入组件或访问用户输入框；可选原生宿主验收需另外准备隐藏 TSF 宿主。`test/独立常驻启动回归/` 覆盖退出作业组和桌面 Shell 交接，运行需要交互式 Windows 桌面，不在无桌面 CI 上执行。

已验证后台管道、隐藏原生宿主、重复提交保护和常驻启动；这些验证不等同于所有真实网页、编辑器和长时间使用场景均已通过。当前发行继续标注为 Windows 安装预览，自动更新源尚未启用。
