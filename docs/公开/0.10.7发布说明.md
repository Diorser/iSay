# iSay 0.10.7：结束录音时填入空输入框

开始录音时即使没有文字光标，也可以先说话，再点进空输入框，最后按录音快捷键结束。只要这段语音尚未写进任何输入框，iSay 会把完整转写提交到结束时确认的空框一次。

这次修复了两个交付条件：结束键触发时就确认目标，不再等识别收尾后重新寻找输入框；将 Chromium 在空编辑器里报告的一个结构换行识别为空。写入前仍核对焦点、正文和选区。原来已经写过正文、目标框有文字、或结束后焦点发生变化时，保留转写，不向新框重发。

原生输入组件仍为 0.9.7。已在隔离 WebView2 验证有、无灰色预测的空框，以及重复结束、已有正文和中途切换焦点。未操作正在使用的 ChatGPT 客户端，未在该客户端验收。
