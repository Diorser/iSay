# iSay 0.10.9：空框收尾与长文整理修复

本版合并 0.10.8 与 0.10.9 的修复，继续作为 Windows x64 完整安装预览发布。

- **结束时填入空框**：开始说话时没有输入焦点，后来点进空输入框，按录音快捷键结束时可以补入完整转写。即使旧位置曾接受过文字，只要原交付失败、旧组合确认结束，且当前空框与焦点重新核验通过，也能接住这一段。
- **本页转写收尾**：修复在 iSay 自己窗口结束录音时，仍等待外部交付标志的阻塞路径。
- **浏览器长文整理**：Chromium 浏览器统一使用核验过的正文范围进行整理；整理结果没有变化时不再发送写入，避免重复应用全文。
- **保留目标保护**：已有正文、用户手动修改、结束后切换焦点，或旧组合尚未确认结束时，不盲目追加或覆盖；完整转写保留在 iSay。

原生输入组件保持 0.9.7。后台验证覆盖真实 TSF 管道与隐藏宿主、离屏 WPF 收尾、隔离 WebView2 的灰色预测开关、失焦返回空框、重复结束、长文与跨段整理。没有操作或重启用户当前 ChatGPT；这些验证不等于所有真实聊天页面与麦克风场景均已验收。

0.10.6 及以上可通过“关于”或托盘菜单检查签名应用更新，也可下载安装完整包。个人设置保留。完整安装包仍未签 Windows 发布者签名；第三方组件来源与预览范围延续现有说明。

## English

This Windows x64 installer preview combines the 0.10.8 and 0.10.9 fixes: validated stop-time delivery into an empty field, removal of a local-transcript finalization wait, and verified-range refinement for Chromium to prevent duplicate long text. Identical refinement results cause no additional write. Existing text and changed targets remain protected. The native input component stays at 0.9.7. Background and isolated-browser checks passed; clean-machine installation, real microphone and every actual chat page are not claimed as fully accepted.
