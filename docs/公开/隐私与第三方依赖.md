# 隐私与第三方依赖

本文描述当前源码预览可确认的行为及分发边界，不承诺未公开第三方服务的内部数据处理方式。

## 音频与文字

iSay 会从选中的麦克风采集音频。采用联网语音服务时，相关音频会发送给该服务；智能整理与可选联网学习可能发送文字、纠错或词条上下文。是否填写自定义密钥不决定服务是否联网，内置适配器也不能被视为离线识别。

第三方服务的账号、缓存、留存期限、处理区域及费用由其自身实现与条款决定。本项目不能替这些服务承诺不留存或不作其他处理。使用前请核对所选择服务的条款；敏感内容应按自己的数据要求选择适合的服务。

额外的语音正文联网学习默认关闭，普通键盘候选的本地学习与其分别控制。个性化、词典与学习功能中的部分实现依赖第三方原生组件，不能把“在本机调用”理解成对该组件完整行为的审计结论。

## 本机保存

默认数据目录为 `%APPDATA%\iSay\VoiceDesk`。转写历史默认开启，保留期限为 30 天；独立录音文件默认不保存。可在“设置 → 通用”调整存储选项并打开数据目录。关闭或清空转写历史不等于删除已经单独保存的录音；录音文件有独立的保存和清理设置。

自定义服务的语音识别与整理密钥保存时使用当前 Windows 用户的 DPAPI 保护，配置文件不写入对应明文。该保护不加密转写历史，也不能防止已取得当前用户权限的进程读取数据。公开配置或提交日志前，仍应移除密钥及其他私人信息。

运行日志、服务错误、词库、缓存与第三方原生组件自己的数据可能包含敏感内容。请勿将整个本机数据目录直接上传到 GitHub Issues。

## 更新与官网

客户端保留自动检查更新选项，正式更新清单地址和验签公钥尚未配置。更新服务启用后，服务提供方会收到正常网络请求所携带的 IP 等连接信息。更新下载和静态官网是不同功能，官网部署不代表已启用客户端自动更新。

静态官网展示产品与源码入口。若后续加入分析、账号、表单或其他数据收集功能，应同步更新相应说明。浏览网站时，托管服务仍会处理正常的访问请求。
