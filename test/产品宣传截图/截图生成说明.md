# 产品宣传截图

这些图片由 **已发布 iSay 0.10.6 的真实 WPF 窗口与控件**离屏渲染生成，不是手工仿制 UI。项目仅通过普通程序集引用读取既有发行布局，不引用桌面源码工程，也不会重新构建或覆盖正在开发的客户端。

## 生成

在仓库根目录执行：

```powershell
dotnet run --project test/产品宣传截图/产品宣传截图.csproj -c Release
```

只更新品牌分享图时使用 `dotnet run --project test/产品宣传截图/产品宣传截图.csproj -c Release -- --social-only`，不会重建五张功能截图。

前置布局：`artifacts/Windows发行/0.10.6-自动更新/布局`。

应用启动被专用预览类拦截，不显示窗口，不连接麦克风、热键、TSF、网络或正式应用动作，不读取现有用户的设置、历史和词库。演示数据仅存在于预览进程内存；截图说明写到本测试目录。

## 演示内容

- `voice-input.png`：给同事发送项目评审通知，展示分段、标点与列表整理后的结果。
- `raw-input.png`：对应同一段口语原文，供网站展示原文与整理结果对照。
- `history.png`：4 条自造历史，包括项目评审、工作安排、文章灵感、周末计划。
- `dictionary.png`：8 条自造热词，其中 3 条为优先词，包含 iSay、Windows、星河工作室、项目评审、用户体验、新手引导、语音输入、产品周报。
- `settings.png`：系统默认麦克风、右 Alt 快捷键、按一次开始/结束、录音时静音、单次 600 秒上限等实际设置界面。
- `social-preview.png`：1200×630 分享图，使用项目自有图标和本地系统字体生成，不包含仿制 UI。

功能截图为 1100×760，均导出到 `website/dist/assets/screenshots/`。网站/README 引用时，请在图注中注明“真实界面，内容为演示数据”；这些图片展示 UI 与示例内容，不代表本次运行过真实语音识别。

全部六张图片均已用 `view_image` 逐张检查：文字可读，无空页面、无裁切、无私人账户或历史数据。
