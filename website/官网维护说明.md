# iSay 官网维护

官网是无需构建的静态页面，发布目录为 `website/dist`，适用于 Cloudflare Pages。所有字体来自操作系统，没有分析、跟踪或外部字体请求。

当前正式地址为 **https://isay-voice.pages.dev/**，英文入口为 **https://isay-voice.pages.dev/?lang=en**。Pages 项目名为 `isay-voice`，生产分支为 `main`，采用直接上传。项目部署在已有 LiteMonitor 的 Cloudflare 账户内。

在项目根目录本地预览：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory website/dist
```

打开 `http://127.0.0.1:4173`，或使用 `?lang=en` 查看英文。语言偏好只保存在浏览器本地。文字演示不会调用麦克风，不连接识别服务。

Cloudflare Pages 使用直接上传时，将 `dist` 目录部署到本项目专属 Pages；使用 Git 集成时，构建命令留空，输出目录填 `website/dist`。不要将本地账号配置、访问令牌或 `.wrangler` 缓存提交到仓库。

采用直接上传的命令行流程如下，在项目根目录执行。先完成登录，仅在 Pages 项目尚不存在时执行 `project create`；后续更新只执行 `pages deploy`。命令固定使用 Wrangler 4.156.0，不依赖机器上可能损坏的全局安装。

```powershell
npm exec --yes --package=wrangler@4.156.0 -- wrangler login
npm exec --yes --package=wrangler@4.156.0 -- wrangler pages deploy website/dist --project-name isay-voice --branch main
```

`isay-voice` 已创建，后续无需重复创建项目。Wrangler 4.156.0 的新项目命令默认会尝试转交 Workers；本次使用 `pages project create isay-voice --production-branch main --force` 创建了用户要求的 Pages 项目，已有项目的部署命令不需要该参数。以 Cloudflare 实际返回的部署 URL 为准。直接上传项目不能原地改为 Git 集成；需要自动发布时，可通过 CI 调用同一个 `pages deploy` 命令。参考 [Cloudflare 官方直接上传文档](https://developers.cloudflare.com/pages/get-started/direct-upload/)。

`_headers` 包含内容安全策略和功能权限限制。当前动态波形需要内联样式属性，因此样式策略允许内联样式，脚本仍限定本站外部文件。波形动画在数次循环后停止，页面滚动动画只执行一次；减少动态效果的系统偏好会关闭动画。

在发布完整安装器之前，继续保留源码预览和第三方组件边界说明。完成运行验收、取得组件分发许可后，再同步更新官网、README 和下载入口，避免先展示无效安装按钮。当前 canonical、Open Graph 图片地址、robots 和 sitemap 均使用 `isay-voice.pages.dev`；绑定自定义域名后需一起更新。
