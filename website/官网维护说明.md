# iSay 官网维护

官网发布目录为 `website/dist`，采用 Cloudflare Pages 直接上传，不依赖前端构建工具。中文入口为 **https://isay-voice.pages.dev/**，英文入口为 **https://isay-voice.pages.dev/en/**。保留旧 `?lang=en` 入口的前端跳转。

页面面向普通 Windows 用户：介绍语音输入、智能整理、个人词典、历史与设置，提供安装下载、免费承诺和常见问题。字体来自系统，不加载分析、跟踪或外部字体。

## 修改与生成

正文、SEO 标签、FAQ、结构化数据和产品资料由 `website/生成官网.py` 统一生成。发行信息只读取 `website/dist/downloads/windows.json`，避免网页版本、安装包和 FAQ 相互矛盾。修改生成器后执行：

```powershell
python -X utf8 website/生成官网.py
node test/官网下载入口回归/官网入口回归.mjs
python -X utf8 test/官网SEO回归/官网SEO回归.py
```

生成器输出中文和英文静态页、`product.json`、`llms.txt`、robots、站点地图、自定义 404，并同步 `_headers` 中两种 JSON-LD 的 CSP 哈希。不要只修改生成后的 HTML。样式与渐进增强脚本分别为 `dist/assets/site.css`、`site.js` 与 `downloads.js`。

图片位于 `dist/assets/screenshots`，使用真实发布版本 WPF 控件和演示数据，不读取用户资料。生成说明见 `test/产品宣传截图/截图生成说明.md`。图片必须有内容，并在图注明确标注演示性质；不得将其描述为真实识别测量结果。更换图片或样式后递增生成器中的资源查询版本，避免浏览器缓存旧布局。

本地预览：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory website/dist
```

分别检查 `/` 与 `/en/`，以及桌面、矮屏和手机宽度。首屏字标的行高、下内边距和外边距用于容纳 `y` 的下伸部分，不要再次压到副标题。正文不依赖 JavaScript；系统偏好减少动态效果时关闭动画。

## 安装包与下载

完整 EXE 托管于 GitHub Release；约 192 MiB，超过 Pages 单文件限制，不放进官网目录，不需要开通 R2。独立发行流程见[完整安装包发布说明](../docs/公开/完整安装包发布说明.md)。

安装包完成公开发行与真实回下载校验后，将发行工具生成的元数据同步到 `dist/downloads/windows.json`。当前为 `0.10.6` 完整安装预览。运行官网生成器，再核对 README 两种语言的版本、链接与体积。

HTML 中保留已公开安装器的静态下载链接，无 JavaScript 也可下载。`downloads.js` 从根路径 `/downloads/windows.json` 读取并核验协议、公开状态、完整回下载状态、版本、架构、文件名、长度、SHA256 与本仓库精确 GitHub EXE 地址，再同步两处按钮。元数据请求失败时保留页面中已公开的入口。撤回版本时必须更新发行元数据并重新生成部署页面，不能只指望运行时脚本隐藏旧链接。

0.10.6 起默认自动检查更新，官网元数据中的 `automaticUpdatesEnabled` 驱动 FAQ、产品资料与 AI 资料中的实际状态。主签名清单位于 `/updates/preview/win-x64.json`，备用为 GitHub Raw；应用 ZIP 位于 `/objects/` 的内容哈希路径，不进入 Git。生成网站时保留本机暂存的 ZIP，部署前核对签名与实际包。发布操作见[自动更新使用与发布](../docs/公开/自动更新使用与发布.md)。旧版用户必须先手动安装一次 0.10.6。

## 部署与核验

Pages 项目 `isay-voice` 已存在，生产分支为 `main`。后续无需新建。固定使用 Wrangler 4.156.0，避开本机可能损坏的全局安装：

```powershell
# 仅登录失效时执行登录，凭据不写入仓库。
npm exec --yes --package=wrangler@4.156.0 -- wrangler login
python -X utf8 scripts/发布/提交搜索收录.py --prepare
$siteRevision = git rev-parse HEAD
npm exec --yes --package=wrangler@4.156.0 -- wrangler pages deploy website/dist --project-name isay-voice --branch main --commit-hash $siteRevision
python -X utf8 scripts/发布/提交搜索收录.py --submit
```

IndexNow 公开验证文件随网站上传，本机配置与提交报告位于忽略的 `artifacts/搜索收录`。它不包含 Cloudflare 登录凭据，不提交到 Git。只有核验线上验证文件及规范页面后才发送通知，成功响应不代表已收录。

部署后运行 `python -X utf8 test/官网SEO回归/线上官网验收.py`，检查中文/英文 HTTP、下载元数据 `no-store`、实际资源哈希、CSP、安装器匿名访问与不存在地址的 HTTP 404。截图做浏览器实渲染验收，HTTP 与 CSS 检查不能替代布局验收。保留证据于 `test/官网验收` 的新目录，不覆盖旧记录。

绑定自定义域名时，统一修改生成器 `BASE`、README、客户端官网配置、搜索提交站点配置，再生成 canonical/hreflang/社交图 URL/robots/sitemap/product/llms；旧域名按路径做 301 到新域名。搜索维护细节见[搜索与AI发现说明](搜索与AI发现说明.md)。

参考：[Cloudflare Pages 直接上传](https://developers.cloudflare.com/pages/get-started/direct-upload/)。
